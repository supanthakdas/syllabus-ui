# Syllabus+ UI

Prompt for Lovable: "Build the UI shell for a web app named 'Syllabus+'. The app is a personal academic assistant for university students. I only need the layout and navigation right now—use mock data and placeholder text. Do not build any backend logic yet.

Theme: Clean, modern, and academic. Use a white and soft blue/teal color palette. Navigation: A persistent sidebar (or top navbar) with two main sections:

1. 'Research & Connect'

2. 'Study Companion'

Pages to Scaffold:

1. Home/Dashboard: A welcoming landing page explaining what Syllabus+ does.

2. Research & Connect (Page): A placeholder layout with a search bar at the top, a sidebar for filters (Department, Teacher Name), and a main area showing a list of mock research paper cards.

3. Study Companion (Page): A placeholder layout with a big 'Upload PDF / Paste Drive Link' drag-and-drop zone. Below that, show two greyed-out placeholder buttons: 'View Resources' and 'Take Quiz'.

Make it fully responsive and ensure clicking the navigation links smoothly switches between these views."
